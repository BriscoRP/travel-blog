An inclusive experience

Accessibility

Project Atlas is being designed so that as many people as possible can navigate, read and understand the website.

How the website is designed

The public shell uses semantic page structure, clear headings, visible keyboard focus, readable contrast and layouts that adapt to smaller screens and browser zoom.

  • Keyboard-accessible navigation and links
  • A skip link to bypass repeated navigation
  • Logical heading order and page landmarks
  • Responsive text without horizontal scrolling
  • Text labels that do not rely on colour or icons alone

How accessibility is checked

This representative website shell will be reviewed for keyboard use, focus visibility, zoom and reflow, colour contrast and screen-reader structure before it is considered ready for publication.

No formal conformance claim is made at this stage.

Known limitations

There are currently no published Place guides to assess. Images, galleries, dated observations and Place-page actions will require their own accessibility review when they are implemented.

Reporting an accessibility problem

No public contact route has been approved for this preview. This section must be reviewed before production publication without exposing private contact details.
