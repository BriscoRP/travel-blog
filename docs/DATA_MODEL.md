# Data Model

## Purpose

This document defines the canonical data model for every published Place within Project Atlas.

It is the single source of truth for the information stored about each place and ensures consistency throughout the website, AI workflow, SEO, filtering and future database.

This document forms part of the Project Atlas Constitution.

Changes should be made deliberately and with consideration of their impact on architecture, workflow and maintainability.

## Identity

Every Place represents one real location personally visited by a member of the family.

| Property | Required | Description |
|--------|:--------:|-------------|
| Name | ✅ | Public display name of the place. |
| Alternative Name(s) | Optional | Historic or commonly used names. |
| Place Type | ✅ | The type of place (e.g. Country Park, Woodland, Beach, Museum, Village, etc.). |
| Publication Status | ✅ | Draft, Review, Published or Archived. |


## Location

The Location section describes where the place is and how visitors can find it.

| Property | Required | Description |
|--------|:--------:|-------------|
| Address | Optional | Postal address if applicable. |
| Town / City | Optional | Nearest town or city. |
| County | ✅ | County or administrative area. |
| Country | ✅ | Country. |
| Postcode | Optional | Postcode if available. |
| Latitude | Optional | GPS latitude. |
| Longitude | Optional | GPS longitude. |
| What3Words | Optional | What3Words location reference. |
| Google Maps | Optional | Google Maps link. |
| Website | Optional | Official website for the location. |

## Visit

The Visit section records when the family visited the place.

| Property | Required | Description |
|--------|:--------:|-------------|
| Visit Date | ✅ | Date of the visit. |
| Month Visited | ✅ | Month of the visit (used for filtering). |
| Day Visited | Optional | Day of the week (used for filtering). |
| Time Visited | Optional | Morning, Afternoon, Evening or Night. |
| Visit Duration | Optional | Approximate length of the visit. |
| Weather | Optional | General weather during the visit. |
| Visited By | ✅ | Family member(s) who visited. |

## Experience

The Experience section captures the family's genuine experience of visiting the place.

| Property | Required | Description |
|--------|:--------:|-------------|
| AI Summary | ✅ | Approximately two-sentence factual overview generated by AI and approved by the editor. |
| Personal Notes | Optional | Family observations, opinions and memories. |
| Recommended | Optional | Whether the family would recommend visiting. |
| Favourite Features | Optional | Highlights or memorable aspects of the visit. |
| Things to Know | Optional | Helpful advice discovered during the visit. |

## Visitor Information

The Visitor Information section contains practical information to help people decide whether to visit.

| Property | Required | Description |
|--------|:--------:|-------------|
| Parking | ✅ | Parking availability and details. |
| Parking Cost | Optional | Parking charges, if applicable. |
| Toilets | ✅ | Availability of public toilets. |
| Entry Cost | ✅ | Free or paid admission. |
| Dogs Allowed | ✅ | Whether dogs are permitted. |
| Pushchair Friendly | ✅ | Suitability for pushchairs. |
| Wheelchair Accessible | ✅ | Accessibility for wheelchair users. |
| Best Time to Visit | Optional | Recommended season or time of year. |
| Opening Times | Optional | Opening hours if applicable. |
| Facilities | Optional | Café, picnic area, playground, visitor centre etc. |

## Media

The Media section contains all assets associated with the visit.

| Property | Required | Description |
|----------|:--------:|-------------|
| Featured Photo | ✅ | Primary image used on listings and social sharing. |
| Gallery | Optional | Additional photographs. |
| Audio Recording | Optional | Original family audio recording. |
| AI Transcript | Optional | Transcript generated from the audio recording. |
| Photo Captions | Optional | Captions for photographs. |
| Photo Credits | Optional | Photographer attribution where required. |

## SEO

The SEO section controls how the page is presented to search engines and social platforms.

| Property | Required | Description |
|----------|:--------:|-------------|
| SEO Title | ✅ | Search engine page title. |
| Meta Description | ✅ | Search engine description. |
| Canonical URL | ✅ | Canonical page URL. |
| Open Graph Image | Optional | Social sharing image. |
| Robots Directive | ✅ | Index / Noindex settings. |
| Tags | ✅ | Consistent tags used for filtering and search. |

## Publishing

The Publishing section controls the publication lifecycle.

| Property | Required | Description |
|----------|:--------:|-------------|
| Editor Approval | ✅ | Final approval before publication. |
| Publish Date | Optional | Date published. |
| Last Reviewed | Optional | Editorial review date. |
| Notes for Editor | Optional | Internal editorial notes. |

## System

The System section contains internal information used by Project Atlas.

| Property | Required | Description |
|----------|:--------:|-------------|
| Unique ID | ✅ | Permanent internal identifier. |
| URL Slug | ✅ | SEO-friendly URL slug. |
| Record Version | ✅ | Internal version number. |
| Date Created | ✅ | Record creation date. |
| Last Updated | ✅ | Record modification date. |
| Source Files | Optional | References to the original photos, audio recordings and notes used to create the published page. |
